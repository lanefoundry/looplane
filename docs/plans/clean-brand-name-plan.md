# Clean brand-name research plan

- [x] Generate coined, non-technical, otter-friendly candidate names.
- [x] Remove awkward pronunciation, unwanted meanings, and generic words.
- [x] Screen package registries, GitHub, domains, apps, and software products.
- [x] Run official USPTO/WIPO/TIPO trademark screens on finalists.
- [x] Deliver only candidates that survive preliminary screening, with caveats.

Constraints:

- Avoid `patch`, `code`, `dev`, `agent`, and `AI` in the main brand.
- Prefer 5-9 letters, two or three syllables, and a natural lowercase CLI form.
- Feel warm and character-led rather than like an infrastructure utility.
- Retain an understandable otter/water association without relying on an obscure fact.
