## Official-query method

Each lowercase candidate was checked using:

- `https://pypi.org/pypi/{name}/json`

Not-found responses only describe the state at query time and do not reserve a namespace. General web search then checked exact-name software, apps, products, and companies; primary product sites and official app pages were preferred for decisive category collisions.
