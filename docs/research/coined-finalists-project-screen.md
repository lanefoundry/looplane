## Method and limitations

- Package and domain results came from official APIs/RDAP endpoints using direct timestamped queries.
- GitHub checks used the official API for exact user/org handles and repository search, with case-insensitive exact-name filtering.
- Web searches were used to discover named entities; primary or registry-adjacent pages were preferred when available.
- Apple results came from Apple's official Search API. Google Play evidence is search-engine based and therefore less complete.
- No social handles, country-by-country corporate registries, common-law trademark usage, phonetic equivalents, or logo/device marks were comprehensively searched.
- Before adoption, run formal exact and phonetic trademark searches in intended markets/classes, refresh every namespace, and register the chosen package/domain/organization together.
