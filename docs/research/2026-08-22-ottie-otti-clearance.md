# Ottie / Otti preliminary naming clearance

Checked: 2026-08-22 (Asia/Taipei)

Scope: packages, open-source projects, commercial software products, and a
preliminary exact/similar trademark screen in the United States, WIPO Madrid
System, European Union sources where accessible, and Taiwan. This is not legal
advice or a professional freedom-to-operate opinion.

## Decision

**Reject both `Ottie` and `Otti` for this coding-agent project.**

`Ottie` has a direct exact-name AI-agent-runtime collision before trademark
analysis is even considered. It also has an active exact US/WIPO technology
mark covering software and class 42 services. `Otti` has several exact software
uses and an exact WIPO/US class 9 trademark record whose US goods include
software and digital images of cartoon otter characters.
