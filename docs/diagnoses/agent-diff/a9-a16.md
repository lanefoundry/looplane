# looplane — Capability Dimensions A9–A16

Target: `/Users/xiaoxu/Projects/looplane` · Cross-reference: `/Users/xiaoxu/Projects/coding-agent-reference`
Scanned: `src/looplane/`, `tests/`, `pyproject.toml`, `docs/`, `.research/`

looplane is a Python Textual TUI coding-agent harness that (a) runs its own native agent loop
(`loop.py` + `tools.py`) against OpenAI-compatible/Anthropic/Gemini providers, and (b) drives
external runtimes (claude-code, codex, opencode, pi, omp) as sandboxed children. Its design
deliberately delegates model-loop concerns to children and keeps approval/security in the harness.
