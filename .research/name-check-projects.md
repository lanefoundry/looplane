# Project/package name collision check

Checked: 2026-08-22 (GitHub repository search via `gh`, exact npm registry lookup via `npm view`, and exact PyPI lookup via `pip index`). This is a practical open-source/package collision check, not a trademark clearance.

## Recommendation

1. **CodePaca — low-to-medium risk, best rename candidate.** No exact GitHub repository result and no exact npm/PyPI package was found. The string is distinctive, but `Paca-AI/paca` is an active AI/agent-adjacent project, so some brand association is still possible. Use `codepaca` consistently and avoid presenting the product simply as “Paca.”
2. **Pybara — low risk.** No exact npm/PyPI package and no meaningful exact GitHub devtool/project collision was found. GitHub results are incidental substrings such as `caPYbara`, not an established `Pybara` coding tool. Most ownable of the animal/Python puns, though less directly connected to the existing `PCA` CLI.
3. **Paca Code — medium risk.** No exact GitHub/npm/PyPI hit, but the leading and spoken brand remains “Paca,” already used by an active AI-native agent collaboration product. Better as a mascot/theme label than the main project name.
4. **Pocket Python — medium-to-high risk.** Exact small GitHub projects exist, and it is close enough to the established `pocketpy` portable Python interpreter to create search/discovery confusion. Avoid for a Python development tool.
5. **Paca — high risk.** Exact npm and PyPI package names are occupied, and [Paca-AI/paca](https://github.com/Paca-AI/paca) is active, AI/agent-adjacent, and had 1,744 GitHub stars at check time.
6. **Otter — very high risk.** The word is saturated in software; exact coding-agent names already include [abcdlsj/otter](https://github.com/abcdlsj/otter), [OtterBot](https://github.com/stoprain/OtterBot), [OtterCode](https://github.com/sss208v/OtterCode), and [otter-code](https://github.com/Heron11/otter-code). There are also large unrelated projects such as [Alibaba Otter](https://github.com/alibaba/otter) and the well-known Otter.ai product. Exact npm `otter` is occupied.
7. **Capybara — very high risk.** [teamcapybara/capybara](https://github.com/teamcapybara/capybara) is a long-established web acceptance-testing framework with 10k+ stars; exact npm and PyPI names are occupied. Coding-agent collisions also exist: [RiverOfLogic/Capybara](https://github.com/RiverOfLogic/Capybara), [capybara-agent](https://github.com/bishabosha/capybara-agent), and [Capybara-CLI](https://github.com/AnonymoDGH/Capybara-CLI).
8. **Axolotl — very high risk.** [axolotl-ai-cloud/axolotl](https://github.com/axolotl-ai-cloud/axolotl) is a major Python/AI fine-tuning project with 12k+ stars and owns the exact PyPI name. [Axolotl-QA/Axolotl](https://github.com/Axolotl-QA/Axolotl) is also an AI-powered VS Code QA agent. Exact npm `axolotl` is occupied by a cryptography package.

## Supporting collisions

- **Pocket Python:** [mysticwillz/pocket-python](https://github.com/mysticwillz/pocket-python) and other exact `PocketPython` repos; [pocketpy/pocketpy](https://github.com/pocketpy/pocketpy) is an active portable Python interpreter with 2k+ stars.
- **Paca package handles:** [`paca` on npm](https://www.npmjs.com/package/paca) and [`paca` on PyPI](https://pypi.org/project/paca/) both resolve to existing packages.
- **Capybara package handles:** [`capybara` on npm](https://www.npmjs.com/package/capybara) and [`capybara` on PyPI](https://pypi.org/project/capybara/) are occupied.
- **Axolotl package handles:** [`axolotl` on npm](https://www.npmjs.com/package/axolotl) and [`axolotl` on PyPI](https://pypi.org/project/axolotl/) are occupied.

## Practical naming direction

- If renaming the project/package: **CodePaca** is the strongest continuity choice; **Pybara** is the cleanest collision profile.
- If only naming the loading animal/mascot: use **Paca** as the animal identity while keeping the product/package `python-coding-agent` / `pca`. Mascot labels do not need to occupy the package namespace and avoid direct project-brand confusion.
- Before publishing under a new brand, separately check domains, social handles, and trademark databases in target markets.
